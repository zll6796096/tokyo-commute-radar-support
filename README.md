# 東京通勤レーダー

東京通勤レーダーは、勤務地への到着時刻と通勤時間の上限から、現在の
交通データで確認できる居住候補エリアを可視化する実験的な Web サービスです。
公共交通オープンデータチャレンジ2026向けに開発しています。

[東京通勤レーダーを開く](https://tokyo-commute-radar-web-788259830737.asia-northeast1.run.app/)

## このリポジトリについて

このリポジトリは、開発者による問い合わせ、使用データ、プライバシー、
セキュリティ情報の公開窓口です。アプリケーションのソースコード公開
リポジトリではありません。

## 現在のデータ範囲

- 代表的な平日である 2026-08-04 の時刻表データを使用します。
- リアルタイム運行情報ではありません。
- 250 m グリッドの中心と四隅を確認する保守的な判定です。
- 駅数とエリア数は、検索条件と利用可能なデータ範囲によって変わります。
- 東京全域、経路の正確性、住宅・安全・金銭上の判断を保証しません。
